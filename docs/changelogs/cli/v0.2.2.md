# CLI and skill — JADE LENS v0.2.2

A bug-fix release for the migration framework: migration checkpoints now work in
the claude.ai app, whose git relay rejects tag pushes.

## Changed

- Migration checkpoints (`migration-start` / `migration-end`) are no longer git
  **tags**. They are now `Jade-Checkpoint: vN-v(N+1)-(start|end)` **commit-message
  trailers on `main`** — the start checkpoint is an empty commit, the end
  checkpoint rides on the `.jade/version` bump commit. They travel with the
  ordinary branch push, so they reach the remote in environments (the claude.ai
  app) whose git relay accepts branch pushes but rejects `refs/tags/*`. `_push`
  no longer passes `--tags`.

## Fixed

- `jadelens migrate` could strand a migration: when the start-tag push failed
  (relay 403), the local tag still existed, so a retried `migrate` call took the
  "resume" path and **never re-attempted the push** — the migration then died at
  `--finalize`. Phase B now always pushes `main` (not gated on local checkpoint
  existence), so a previously-failed push self-heals on the next call.
